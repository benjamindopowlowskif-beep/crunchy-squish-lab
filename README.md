# 脆皮捏捏实验室 · Crunchy Squish Lab

一个本地运行的 Three.js 单页减压玩具。默认草莓奶油小熊，支持局部持续按压、拖动揉捏、慢回弹、累计脆壳裂纹与声音开关。

## 安装与启动

需要 Node.js 22.12+（推荐 Node.js 24）。在项目目录打开终端：

```sh
npm install
npm run dev
```

用 Chrome 打开终端显示的本地地址，通常为 http://127.0.0.1:5173 。关闭终端中的服务可按 Ctrl+C。

```sh
npm run build
npm run preview
```

`dist/` 是生产构建结果。请通过 HTTP 服务打开，不要直接双击 HTML。所有运行资源均来自本地，没有在线字体、CDN、后端或外部运行依赖。

## 玩法与录屏

- 在小熊身体上按住约 1 秒，按压逐渐加深；按住拖动可以揉捏。
- 松手后约 1.5～3 秒慢慢鼓回来，裂纹继续保留。
- 同一区域再次按压可叠加裂纹；“换一个新的”清空形变和裂纹。
- 默认允许声音，首次有效点击后浏览器才会启动音频。点击声音按钮静音。
- 推荐 1440×810 或 1920×1080 录屏：先静置 2 秒 → 压肚子 2 秒 → 拖动揉捏 4 秒 → 松手展示回弹 3 秒 → 重复按压展示裂纹 → 换新。录屏软件需开启系统声音采集。

## 实现与简化

**实际实现：** Raycaster 命中检测；通过三角形重心坐标找回原始表面接触点；距离衰减控制顶点级局部凹陷和周边鼓起；拖动残留多个衰减形变区域；所有五官和裂纹随同一形变场运动；持续按压逐渐加深；指数阻尼慢回弹；外壳和内层为独立网格；外壳纹理开口露出哑光奶油色内层；裂纹累计并可重置；鼠标/触摸事件与指针捕获；失焦、取消触摸时自动松手。

**视觉模拟：** 形变是局部数学形变场，不是有限元软体求解。外围鼓起近似补偿体积，不保证严格体积守恒。裂纹按接触点程序化生成，外壳开口由透明度裁切实现，并非真实断裂拓扑或碎片碰撞。模型由平滑椭球组成，肢体接合处可能看出造型拼接。回弹为柔和指数衰减，不模拟完整材料滞回。

**声音说明：** 当前自带音效是分层随机噪声颗粒经过滤波、包络与动态压缩形成的程序化脆裂/摩擦声音，不是真实 ASMR 录音。轻、中、重、回弹四档均可直接播放，已提供真实录音替换接口。将你有使用权的 `.wav`/`.mp3` 文件放入 `public/audio/`，修改 `src/samples.js`：

```js
export default {
  light: ['/audio/light-01.wav'],
  medium: ['/audio/medium-01.wav'],
  heavy: ['/audio/heavy-01.wav'],
  release: ['/audio/release-01.wav'],
};
```

每档可填多个文件，播放时随机选取并微调音调。没有填写的档位继续使用程序化声音。

**第一版边界：** 单指/单鼠标输入；鼠标没有物理压力，使用按住时长模拟力度；裂纹最多保留 100 组以控制绘制成本，达到上限后仍可揉捏，换新后重新累计；不保存跨刷新状态；无脆皮滑杆或多款模型。推荐支持 WebGL 的较新 Chrome，低性能设备可能需要降低窗口尺寸。

## 开发验收

`qa.cjs` 是当前机器的开发验收脚本，使用本机 Chrome 和 Codex 自带的 Playwright；其中路径与当前机器相关，不影响应用安装和运行。截图保存在 `.qa/`。主要检查局部形变、慢回弹、裂纹保留、重置、声音按钮、桌面和移动端布局、浏览器错误。
