# 脆皮捏捏实验室 · Crunchy Squish Lab

一个本地运行的 Three.js 单页减压玩具。支持蜜桃团团、奶冻垂耳兔、焦糖布丁猫、橘子小啾与经典小熊五款造型，提供局部持续按压、拖动揉捏、慢回弹、蜡壳破碎与声音开关。

## 五款捏捏

桌面右侧面板、手机底部面板可选择不同玩具。默认蜜桃。切换会生成完好的一只，上一款的破损不保留；静音设置在切换时保留。

| 款式 | 外壳与内芯 | 交互区别 |
| --- | --- | --- |
| 蜜桃团团 | 粉白渐变薄壳、蜜桃粉凝胶与细小珠粒 | 更密、更薄的碎片，中慢回弹 |
| 奶冻垂耳兔 | 奶白淡紫垂耳、紫色奶冻、珠粒与圆角奶冻块 | 轻柔短酥裂声，宽范围揉捏，奶冻块随按压轻微变扁 |
| 焦糖布丁猫 | 金黄主体、焦糖色顶壳、金黄奶馅 | 较厚大片，较难碎化，按压更深、回弹最慢 |
| 橘子小啾 | 橘色圆壳、橙色果冻与大珠粒 | 较厚弧片，按压更浅、回弹最快 |
| 奶油小熊 | 矮胖身体、小圆耳、奶油口鼻、树莓软心 | 中等按压与回弹，同系列图片缩略图 |

模型为按概念图方向制作的程序化 3D 造型，不是图片的逐像素复刻。侧栏缩略图为之前生成的概念图，原图保存在 `public/concepts/`。当前内馅仍是局部形变与回弹，尚未实现整个玩具永久揉成一团的材料混合。

造型已按概念图重新调整为更矮胖的比例：蜜桃有上下双瓣凹槽与叶脉；兔耳从头顶沿两侧垂下；布丁猫的耳尖和小爪通过同一主体曲面塑形，减少拼接；橘子采用矮圆身体与小翅膀。五官沿模型表面定位，腮红使用渐变颜色，蜡壳带细微凹凸纹理。所有新曲面同步用于壳片生成，保留破壳和揉捏能力。

## 安装与启动

需要 Node.js 22.12+（推荐 Node.js 24）。在项目目录打开终端：

```sh
npm install
npm run dev
```

用 Chrome 打开终端显示的本地地址，通常为 http://127.0.0.1:5173 。关闭终端中的服务可按 Ctrl+C。

```sh
npm run build
npm run preview
```

`dist/` 是生产构建结果。请通过 HTTP 服务打开，不要直接双击 HTML。所有运行资源均来自本地，没有在线字体、CDN、后端或外部运行依赖。

## 玩法与录屏

- 在小熊身体上按住约 1 秒，按压逐渐加深；按住拖动可以揉捏。
- 初次按压会压开不规则蜡片，看到有厚度的断面和露出的树莓色凝胶、小珠子。
- 在同一区域继续按压或反复揉捏，蜡片会分成更小的碎片，再逐渐嵌入凝胶。破坏程度只随揉捏增加，不会在松手后自动消失。
- 松手后约 1.5～3 秒内芯慢慢鼓回来，外壳保持破碎状态；“换一个新的”恢复完整蜡壳并清除碎片。
- 默认允许声音，首次有效点击后浏览器才会启动音频。点击声音按钮静音。
- 推荐 1440×810 或 1920×1080 录屏：先静置 2 秒 → 压肚子 2 秒 → 拖动揉捏 4 秒 → 松手展示回弹 3 秒 → 重复按压展示裂纹 → 换新。录屏软件需开启系统声音采集。

## 实现与简化

**实际实现：** Raycaster 命中检测；通过三角形重心坐标找回原始表面接触点；距离衰减控制顶点级局部凹陷和周边鼓起；拖动残留多个衰减形变区域；持续按压逐渐加深；指数阻尼慢回弹；外壳与凝胶为独立网格。蜡壳使用不规则 Voronoi 多边形分区，受压区域累计损伤后从完整表面移除，并替换成有正面、背面和厚度的立体薄片；薄片旋转翘起，继续揉捏后分裂为较小三角碎片并逐渐下沉、缩小，部分被内芯表面遮挡，形成嵌入效果。破口中显示独立小球几何体，随揉捏移动。碎片采用合批几何体，小珠子采用实例化绘制，避免每一片都新增绘制调用。所有破损均可重置。支持鼠标/触摸事件、指针捕获、失焦自动松手。

**视觉模拟：** 内芯形变是局部数学形变场，不是有限元软体或真实流体求解。外围鼓起近似补偿体积，不保证严格体积守恒。壳片形状预先分区，破损由接触点附近累计受压触发，完整壳层的对应区域使用透明度裁切移除；碎片本身是立体几何体，但没有刚体碰撞求解。碎片“揉进凝胶”通过旋转、缩小、下沉和遮挡表现，不是蜡真正熔化或流体混合。内芯使用高光与柔和反射表现有色固态凝胶，不是透明液体；小珠子不会爆浆或单独碰撞。模型由平滑椭球组成，肢体接合处可能看出造型拼接。回弹为柔和指数衰减，不模拟完整材料滞回。

**声音说明：** 当前自带音效是分层随机噪声颗粒经过滤波、包络与动态压缩形成的程序化脆裂/摩擦声音，不是真实 ASMR 录音。轻、中、重、回弹四档均可直接播放，已提供真实录音替换接口。将你有使用权的 `.wav`/`.mp3` 文件放入 `public/audio/`，修改 `src/samples.js`：

```js
export default {
  light: ['/audio/light-01.wav'],
  medium: ['/audio/medium-01.wav'],
  heavy: ['/audio/heavy-01.wav'],
  release: ['/audio/release-01.wav'],
};
```

每档可填多个文件，播放时随机选取并微调音调。没有填写的档位继续使用程序化声音。

五款程序化音色分别为：蜜桃的短促细脆声、兔子的轻柔短酥裂声、布丁猫的低频闷软声、橘子的稀疏颗粒啵脆声，以及小熊的中频咔嚓声。兔子已降低音量、高频与颗粒密度，缩短尾音，并将破壳最短触发间隔改为 0.30 秒，减少噪声叠加。拖动触发各自的揉馅摩擦声，松手触发轻微回弹声。切换款式淡出前一款余音，静音设置保持不变。仍不是真实录制的 ASMR。

也可按款式提供真实录音，例如在 `src/samples.js` 中加入 `bunny: { light: ['/audio/bunny-light.wav'], knead: ['/audio/bunny-rub.wav'], release: ['/audio/bunny-release.wav'] }`。支持 `peach`、`bunny`、`pudding`、`orange`、`bear`，优先播放对应款式的录音，随后回退到通用录音或程序化声音。

**当前边界：** 单指/单鼠标输入；鼠标没有物理压力，使用按住时长模拟力度；蜡壳分区数量固定，破损程度最多到碎片嵌入，已经揉碎的位置仍可继续揉内芯；不保存跨刷新状态或切换前的破损；不提供参数调试面板。推荐支持 WebGL 的较新 Chrome，低性能设备可能需要降低窗口尺寸。

## 开发验收

`qa.cjs` 是当前机器的开发验收脚本，使用本机 Chrome 和 Codex 自带的 Playwright；其中路径与当前机器相关，不影响应用安装和运行。截图保存在 `.qa/`。主要检查局部形变、慢回弹、立体蜡片、反复按压后的碎化和嵌入、破损保留、重置后几何体数量、声音按钮、桌面和触屏输入、浏览器错误。
